Docker · Windows / Linux / macOS

Bootstrap Shotloom

Clone the repo, run the bootstrap script, open http://127.0.0.1:8765. No installer exe — Docker pulls the stack and models on first run. 

# Linux / macOS / WSL
git clone https://github.com/Shotloom/Shotloom.git
cd Shotloom
./scripts/bootstrap.sh
Open on GitHub

Windows PowerShell: .\scripts\bootstrap.ps1

After bootstrap

From Docker up to first export

01

Compose up

Bootstrap builds images and waits for the API. Optional GPU compose file for NVIDIA on Linux/WSL2.

02

Open dashboard

Media tab: drop 2–4 multicam clips. Settings: montage rhythm and caption style. Captions: preview and edit.

03

Export platforms

Queue YouTube, TikTok, Instagram, Facebook profiles. Artifacts land in your project directory on disk.

Requirements

  • Docker Desktop or Engine 24+
  • 16 GB RAM recommended
  • Disk for proxies + exports
  • GPU optional (faster analysis)
