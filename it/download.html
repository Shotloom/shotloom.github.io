Docker · Windows / Linux / macOS

Bootstrap Shotloom

Clona il repo, lancia lo script bootstrap, apri http://127.0.0.1:8765. Niente installer .exe — Docker avvia lo stack e i modelli al primo run. 

# Linux / macOS / WSL
git clone https://github.com/Shotloom/Shotloom.git
cd Shotloom
./scripts/bootstrap.sh
Apri su GitHub

Windows PowerShell: .\scripts\bootstrap.ps1

Dopo il bootstrap

Da Docker avviato al primo export

01

Compose up

Il bootstrap costruisce le immagini e attende l'API. Compose GPU opzionale per NVIDIA su Linux/WSL2.

02

Apri la dashboard

Tab Media: trascina 2–4 clip multicam. Settings: ritmo montaggio e stile caption. Captions: anteprima e modifica.

03

Export piattaforme

Accoda profili YouTube, TikTok, Instagram, Facebook. Gli artifact restano nella directory progetto su disco.

Requisiti

  • Docker Desktop o Engine 24+
  • 16 GB RAM consigliati
  • Disco per proxy ed export
  • GPU opzionale (analisi più veloce)
