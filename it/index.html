03. Dove finiscono i rushes

I tuoi footage non lasciano la macchina

Episodi non pubblicati, eventi clienti, rushes interviste — la privacy è perché i creator evitano NLE cloud. Shotloom gira in Docker su hardware che controlli tu. Provalo stasera senza chiederti dove finisce il multicam.

Niente timeline cloud forzata

Ingest, sync ed export in locale. API cloud opzionali restano off finché non le configuri.

Docker sul tuo box o VPS

Laptop dev, workstation o server locked-down — bind su localhost di default. Tu scegli l'esposizione.

Pipeline aperta, verificabile

Sorgente su GitHub. Ispeziona cosa gira prima di puntarlo a footage clienti.
