# Shotloom Website

Official landing site for **Shotloom** — local AI multicam NLE: sync, rough cut, captions, and platform exports (YouTube / TikTok / Instagram / Facebook).

Built with **Jekyll** and deployed on GitHub Pages.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Or with Docker:

```bash
docker compose up
```

Open http://localhost:4000

## Documentation

MkDocs-style HTML in `docs/` is a **placeholder** on this site. Canonical docs live in the main repo:

- [github.com/Shotloom/Shotloom/tree/main/docs](https://github.com/Shotloom/Shotloom/tree/main/docs)

To publish full docs into `docs/` from the main repo, run the publish script there and push this repo.

Main project: [github.com/Shotloom/Shotloom](https://github.com/Shotloom/Shotloom)
